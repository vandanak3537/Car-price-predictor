# Car Price Predictor

A Machine Learning-based web application that predicts the estimated selling price of used cars based on their specifications.

## Live Demo
https://car-price-vercel.vercel.app/

## Features
- Predicts used car selling prices.
- Simple and user-friendly interface.
- Takes car specifications as input.
- Provides instant price predictions.

## Technologies Used
- Python
- Pandas & NumPy
- Scikit-learn
- HTML, CSS & JavaScript
- Vercel

## Machine Learning Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Model Training
5. Model Evaluation
6. Web Deployment
